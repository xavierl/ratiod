# ratiod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ratiod` in Rust: a lightweight fake BitTorrent client driven by a modern Svelte 5 web UI where you drop your `.torrent` files, shipped as a Docker image for a NAS.

**Architecture:** A single Rust binary (lib + bin). An `engine` actor (one tokio task) owns all the state and receives commands over `mpsc`; it publishes a `Snapshot` through `watch`, streamed over SSE by `axum`. HTTP announces go through `hyper` (no implicit headers) and reproduce the `.client` profiles exactly. The compiled Svelte frontend is embedded with `rust-embed`.

**Tech Stack:** Rust 2024 (tokio, axum 0.8, hyper 1 + hyper-rustls/ring/webpki-roots, rand 0.10, rand_regex 0.19, regex, notify 8, rust-embed 8, sha1 0.11, serde, tracing) · Svelte 5 + Vite 8 + Tailwind CSS 4 + TypeScript 5.9 + Vitest 5 · Docker multi-stage → `scratch`.

**Spec:** `docs/superpowers/specs/2026-10-14-ratiod-design.md`

## Global Constraints

- Binary, crate and image name: `ratiod`. Private GitHub repository `xavierl/ratiod`, branch `main`.
- The `.client` files are used **unmodified** (95 profiles, copied from the upstream ratio-emulator repository, folder `resources/clients/`).
- `config.json` keeps the existing keys: `minUploadRate`, `maxUploadRate`, `simultaneousSeed`, `client`, `keepTorrentWithZeroLeechers`, `uploadRatioTarget`. Defaults: 30, 170, 200, latest qBittorrent profile (`qbittorrent-5.2.4.client`), `true`, `-1`. 1 kB = 1000 bytes.
- Environment variables: `RATIOD_BIND` (default `127.0.0.1:5081`, image `0.0.0.0:5081`), `RATIOD_DATA_DIR` (default `data`, image `/data`), `RATIOD_PEER_PORT` (default random 49152–65534, image `49200`), `RATIOD_AUTOSTART` (default `true`), `RUST_LOG` (default `info`).
- No authentication, no CORS, no call to any third-party service other than trackers.
- Announce request: `Host` first, then the profile's headers in their order, in Title-Case, nothing else. Query appended as is, never re-encoded.
- User-visible text (UI, API errors, tracker errors) in **French**; logs and code in English.
- No `unwrap()`/`expect()` on external data (file, network, HTTP request) in non-test code.
- Apache 2.0 license; `NOTICE` credits the origin of the `.client` profiles.
- No CI, no image publishing.
- `cargo` commands run at the repository root; `npm` commands in `web/`.
- Commit messages end with the line: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Same torrent under two file names** (manual copy into the folder, or upload of a duplicate while another one is active) → one seed per info_hash, never two. Tested in Task 10 (`duplicate_file_is_not_seeded_twice`) and Task 9 (`add_rejects_duplicate`).
2. **Tracker answering 200 with an HTML page, or with a gzip response** → HTML counts as a clean failure (no panic), gzip is decoded. Tested in Task 7 (`html_body_is_invalid`, `gzip_body_is_decoded`).
3. **Invalid config change while seeding** (unknown client) → 400, nothing written, seeding continues without restarting. Tested in Task 10 (`invalid_config_is_rejected_and_seeding_continues`).
4. **Hostile file name on upload** (`../../evil.torrent`, special characters, empty name) → file written in `torrents/` under a sanitized name. Tested in Task 9 (`add_sanitizes_hostile_filename`).
5. **Shutdown while a tracker stops answering** (Stop, `docker stop`) → shutdown still completes within the 5 s limit. Tested in Task 10 (`stop_finishes_even_if_tracker_hangs`).

```rust
//! Fixture builders shared by unit and integration tests.

/// Encodes a bencode byte string.
pub fn bstr(s: &[u8]) -> Vec<u8> {
    let mut out = format!("{}:", s.len()).into_bytes();
    out.extend_from_slice(s);
    out
}

/// A single-file `info` dictionary.
pub fn info_dict(name: &str, size: u64) -> Vec<u8> {
    let mut out = b"d".to_vec();
    out.extend(bstr(b"length"));
    out.extend(format!("i{size}e").into_bytes());
    out.extend(bstr(b"name"));
    out.extend(bstr(name.as_bytes()));
    out.extend(bstr(b"piece length"));
    out.extend(b"i16384e");
    out.extend(bstr(b"pieces"));
    out.extend(bstr(&[0u8; 20]));
    out.push(b'e');
    out
}

/// A single-file torrent announcing to one tracker.
pub fn torrent_file(name: &str, size: u64, announce: &str) -> Vec<u8> {
    torrent_with_trackers(name, size, &[announce])
}

/// A single-file torrent with one tracker per `announce-list` tier.
pub fn torrent_with_trackers(name: &str, size: u64, trackers: &[&str]) -> Vec<u8> {
    let mut out = b"d".to_vec();
    out.extend(bstr(b"announce"));
    out.extend(bstr(trackers.first().copied().unwrap_or("").as_bytes()));
    out.extend(bstr(b"announce-list"));
    out.push(b'l');
    for tracker in trackers {
        out.push(b'l');
        out.extend(bstr(tracker.as_bytes()));
        out.push(b'e');
    }
    out.push(b'e');
    out.extend(bstr(b"info"));
    out.extend(info_dict(name, size));
    out.push(b'e');
    out
}

/// A successful tracker announce response.
pub fn tracker_response(interval: u32, complete: u32, incomplete: u32) -> Vec<u8> {
    format!("d8:completei{complete}e10:incompletei{incomplete}e8:intervali{interval}e5:peers0:e").into_bytes()
}
```

```rust
//! Minimal bencode decoder. Dictionaries keep their raw byte span so the
//! torrent info-hash can be computed without re-encoding.

use thiserror::Error;

const MAX_DEPTH: usize = 64;

#[derive(Debug, Clone, PartialEq)]
pub enum Value<'a> {
    Int(i64),
    Bytes(&'a [u8]),
    List(Vec<Value<'a>>),
    /// Entries in file order, then the raw bytes of the whole dictionary.
    Dict(Vec<(&'a [u8], Value<'a>)>, &'a [u8]),
}

#[derive(Debug, Clone, PartialEq, Eq, Error)]
pub enum BencodeError {
    #[error("unexpected end of data")]
    Eof,
    #[error("invalid bencode at byte {0}")]
    Invalid(usize),
    #[error("nesting too deep")]
    TooDeep,
}

/// Decodes the first bencoded value in `data`; trailing bytes are ignored.
pub fn decode(data: &[u8]) -> Result<Value<'_>, BencodeError> {
    Parser { data, pos: 0 }.value(0)
}

impl<'a> Value<'a> {
    pub fn get(&self, key: &str) -> Option<&Value<'a>> {
        match self {
            Value::Dict(entries, _) => entries.iter().find(|(k, _)| *k == key.as_bytes()).map(|(_, v)| v),
            _ => None,
        }
    }

    pub fn as_int(&self) -> Option<i64> {
        match self {
            Value::Int(n) => Some(*n),
            _ => None,
        }
    }

    pub fn as_bytes(&self) -> Option<&'a [u8]> {
        match self {
            Value::Bytes(b) => Some(b),
            _ => None,
        }
    }

    pub fn as_str(&self) -> Option<&'a str> {
        std::str::from_utf8(self.as_bytes()?).ok()
    }

    pub fn as_list(&self) -> Option<&[Value<'a>]> {
        match self {
            Value::List(items) => Some(items),
            _ => None,
        }
    }

    /// Raw bytes of a dictionary, exactly as they appear in the input.
    pub fn raw(&self) -> Option<&'a [u8]> {
        match self {
            Value::Dict(_, raw) => Some(raw),
            _ => None,
        }
    }
}

struct Parser<'a> {
    data: &'a [u8],
    pos: usize,
}

impl<'a> Parser<'a> {
    fn peek(&self) -> Result<u8, BencodeError> {
        self.data.get(self.pos).copied().ok_or(BencodeError::Eof)
    }

    fn value(&mut self, depth: usize) -> Result<Value<'a>, BencodeError> {
        if depth > MAX_DEPTH {
            return Err(BencodeError::TooDeep);
        }
        match self.peek()? {
            b'i' => {
                self.pos += 1;
                Ok(Value::Int(self.number(b'e')?))
            }
            b'l' => {
                self.pos += 1;
                let mut items = Vec::new();
                while self.peek()? != b'e' {
                    items.push(self.value(depth + 1)?);
                }
                self.pos += 1;
                Ok(Value::List(items))
            }
            b'd' => {
                let start = self.pos;
                self.pos += 1;
                let mut entries = Vec::new();
                while self.peek()? != b'e' {
                    let key = self.bytes()?;
                    let value = self.value(depth + 1)?;
                    entries.push((key, value));
                }
                self.pos += 1;
                Ok(Value::Dict(entries, &self.data[start..self.pos]))
            }
            b'0'..=b'9' => Ok(Value::Bytes(self.bytes()?)),
            _ => Err(BencodeError::Invalid(self.pos)),
        }
    }

    fn number(&mut self, terminator: u8) -> Result<i64, BencodeError> {
        let start = self.pos;
        let len = self.data[start..].iter().position(|&b| b == terminator).ok_or(BencodeError::Eof)?;
        let text = std::str::from_utf8(&self.data[start..start + len]).map_err(|_| BencodeError::Invalid(start))?;
        let n = text.parse::<i64>().map_err(|_| BencodeError::Invalid(start))?;
        self.pos = start + len + 1;
        Ok(n)
    }

    fn bytes(&mut self) -> Result<&'a [u8], BencodeError> {
        let start = self.pos;
        if !self.peek()?.is_ascii_digit() {
            return Err(BencodeError::Invalid(start));
        }
        let len = usize::try_from(self.number(b':')?).map_err(|_| BencodeError::Invalid(start))?;
        let end = self.pos.checked_add(len).ok_or(BencodeError::Invalid(start))?;
        if end > self.data.len() {
            return Err(BencodeError::Eof);
        }
        let bytes = &self.data[self.pos..end];
        self.pos = end;
        Ok(bytes)
    }
}
```

```rust
    pub trackers: Vec<String>,
}

#[derive(Debug, Error)]
pub enum TorrentError {
    #[error("fichier .torrent illisible : {0}")]
    Bencode(#[from] BencodeError),
    #[error("champ `{0}` absent ou invalide")]
    Field(&'static str),
    #[error("aucun tracker HTTP(S) dans ce torrent")]
    NoHttpTracker,
}

impl MockedTorrent {
    pub fn parse(data: &[u8]) -> Result<Self, TorrentError> {
        let root = bencode::decode(data)?;
        let info = root.get("info").ok_or(TorrentError::Field("info"))?;
        let raw_info = info.raw().ok_or(TorrentError::Field("info"))?;
        let mut info_hash = [0u8; 20];
        info_hash.copy_from_slice(&Sha1::digest(raw_info));
        let name = info
            .get("name")
            .and_then(Value::as_bytes)
            .map(|b| String::from_utf8_lossy(b).into_owned())
            .ok_or(TorrentError::Field("name"))?;
        let size = torrent_size(info)?;
        let trackers = http_trackers(&root);
        if trackers.is_empty() {
            return Err(TorrentError::NoHttpTracker);
        }
        Ok(Self { info_hash, name, size, trackers })
    }

    pub fn info_hash_hex(&self) -> String {
        hex::encode(self.info_hash)
    }
}

fn torrent_size(info: &Value<'_>) -> Result<u64, TorrentError> {
    if let Some(length) = info.get("length").and_then(Value::as_int) {
        return u64::try_from(length).map_err(|_| TorrentError::Field("length"));
    }
    let files = info.get("files").and_then(Value::as_list).ok_or(TorrentError::Field("length"))?;
    files.iter().try_fold(0u64, |total, file| {
        let length = file
            .get("length")
            .and_then(Value::as_int)
            .and_then(|l| u64::try_from(l).ok())
            .ok_or(TorrentError::Field("files.length"))?;
        total.checked_add(length).ok_or(TorrentError::Field("files.length"))
    })
}

fn http_trackers(root: &Value<'_>) -> Vec<String> {
    let mut urls = Vec::new();
    if let Some(tiers) = root.get("announce-list").and_then(Value::as_list) {
        for tier in tiers {
            for url in tier.as_list().unwrap_or(&[]) {
                if let Some(url) = url.as_str() {
                    urls.push(url.trim().to_owned());
                }
            }
        }
    }
    if urls.is_empty() {
        if let Some(url) = root.get("announce").and_then(Value::as_str) {
            urls.push(url.trim().to_owned());
        }
    }
    let mut seen = HashSet::new();
    urls.into_iter()
        .filter(|url| {
            let lower = url.to_ascii_lowercase();
            lower.starts_with("http://") || lower.starts_with("https://")
        })
        .filter(|url| seen.insert(url.clone()))
        .collect()
}
```

```rust
//! Configurable URL encoder: bytes matching the exclusion pattern are kept,
//! every other byte becomes `%xx` in the configured hex case.

use regex::Regex;

#[derive(Debug, Clone)]
pub struct UrlEncoder {
    keep: [bool; 256],
    upper_hex: bool,
}

impl UrlEncoder {
    /// `exclusion_pattern` is matched against each byte seen as a Latin-1 char.
    pub fn new(exclusion_pattern: &str, upper_hex: bool) -> Result<Self, regex::Error> {
        let re = Regex::new(&format!("^(?:{exclusion_pattern})$"))?;
        let mut keep = [false; 256];
        let mut buf = [0u8; 4];
        for byte in 0..=255u8 {
            keep[usize::from(byte)] = re.is_match(char::from(byte).encode_utf8(&mut buf));
        }
        Ok(Self { keep, upper_hex })
    }

    pub fn encode(&self, bytes: &[u8]) -> String {
        let mut out = String::with_capacity(bytes.len() * 3);
        for &byte in bytes {
            if self.keep[usize::from(byte)] {
                out.push(char::from(byte));
            } else if self.upper_hex {
                out.push_str(&format!("%{byte:02X}"));
            } else {
                out.push_str(&format!("%{byte:02x}"));
            }
        }
        out
    }
}
```

```rust
//! Peer-id and key generation algorithms from `.client` profiles.
//! Values are Latin-1 byte strings (profiles only use chars ≤ 0xFF).

use rand::RngExt;
use serde::Deserialize;
use thiserror::Error;

pub const PEER_ID_LEN: usize = 20;
const HEX_UPPER: &[u8; 16] = b"0123456789ABCDEF";

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(tag = "type", rename_all = "SCREAMING_SNAKE_CASE")]
pub enum AlgorithmConfig {
    Regex {
        pattern: String,
    },
    #[serde(rename_all = "camelCase")]
    RandomPoolWithChecksum {
        prefix: String,
        characters_pool: String,
        base: usize,
    },
    Hash {
        length: usize,
    },
    HashNoLeadingZero {
        length: usize,
    },
    #[serde(rename = "DIGIT_RANGE_TRANSFORMED_TO_HEX_WITHOUT_LEADING_ZEROES", rename_all = "camelCase")]
    DigitRange {
        inclusive_lower_bound: u64,
        inclusive_upper_bound: u64,
    },
}

#[derive(Debug, Error)]
#[error("{0}")]
pub struct AlgorithmError(pub String);

pub enum Algorithm {
    Regex(rand_regex::Regex),
    Pool { prefix: Vec<u8>, pool: Vec<u8>, base: usize },
    Hex { length: usize, strip_leading_zeros: bool },
    DigitRange { lower: u64, upper: u64 },
}

impl Algorithm {
    pub fn compile(cfg: &AlgorithmConfig) -> Result<Self, AlgorithmError> {
        Ok(match cfg {
            AlgorithmConfig::Regex { pattern } => Algorithm::Regex(
                rand_regex::Regex::compile(pattern, 16)
                    .map_err(|e| AlgorithmError(format!("regex invalide `{pattern}` : {e}")))?,
            ),
            AlgorithmConfig::RandomPoolWithChecksum { prefix, characters_pool, base } => {
                let prefix = latin1(prefix)?;
                let pool = latin1(characters_pool)?;
                if prefix.is_empty() || prefix.len() >= PEER_ID_LEN {
                    return Err(AlgorithmError(format!("prefix doit faire 1 à {} caractères", PEER_ID_LEN - 1)));
                }
                if *base == 0 || *base > pool.len() {
                    return Err(AlgorithmError("base doit être entre 1 et la taille de charactersPool".into()));
                }
                Algorithm::Pool { prefix, pool, base: *base }
            }
            AlgorithmConfig::Hash { length } | AlgorithmConfig::HashNoLeadingZero { length } => {
                if *length == 0 {
                    return Err(AlgorithmError("length doit être supérieur à 0".into()));
                }
                Algorithm::Hex {
                    length: *length,
                    strip_leading_zeros: matches!(cfg, AlgorithmConfig::HashNoLeadingZero { .. }),
                }
            }
            AlgorithmConfig::DigitRange { inclusive_lower_bound: lower, inclusive_upper_bound: upper } => {
                if lower > upper {
                    return Err(AlgorithmError("inclusiveLowerBound doit être ≤ inclusiveUpperBound".into()));
                }
                Algorithm::DigitRange { lower: *lower, upper: *upper }
            }
        })
    }

    pub fn generate(&self) -> Vec<u8> {
        let mut rng = rand::rng();
        match self {
            Algorithm::Regex(re) => {
                let s: String = rng.sample(re);
                // Profiles only use chars ≤ U+00FF; anything else cannot be sent as one byte.
                s.chars().map(|c| u8::try_from(u32::from(c)).unwrap_or(b'?')).collect()
            }
            Algorithm::Pool { prefix, pool, base } => {
                let suffix_len = PEER_ID_LEN - prefix.len();
                let mut out = prefix.clone();
                let mut total = 0usize;
                for _ in 0..suffix_len - 1 {
                    let index = usize::from(rng.random::<u8>()) % base;
                    total += index;
                    out.push(pool[index]);
                }
                let check = if total % base == 0 { 0 } else { base - total % base };
                out.push(pool[check]);
                out
            }
            Algorithm::Hex { length, strip_leading_zeros } => {
                let hex: Vec<u8> = (0..*length).map(|_| HEX_UPPER[rng.random_range(0..16)]).collect();
                if *strip_leading_zeros {
                    hex.into_iter().skip_while(|&c| c == b'0').collect()
                } else {
                    hex
                }
            }
            Algorithm::DigitRange { lower, upper } => format!("{:x}", rng.random_range(*lower..=*upper)).into_bytes(),
        }
    }
}

fn latin1(s: &str) -> Result<Vec<u8>, AlgorithmError> {
    s.chars()
        .map(|c| u8::try_from(u32::from(c)).map_err(|_| AlgorithmError(format!("caractère non Latin-1 : {c}"))))
        .collect()
}
```

```rust
        }
        Ok(Self {
            algorithm: Algorithm::compile(&cfg.algorithm)?,
            refresh_on: cfg.refresh_on,
            refresh_every: Duration::from_secs(refresh_every),
            casing: cfg.key_case,
            current: None,
            per_torrent: HashMap::new(),
        })
    }

    /// A fresh value that does not affect the generator state (used for validation).
    pub fn sample(&self) -> Vec<u8> {
        generate(&self.algorithm, self.casing)
    }

    pub fn get(&mut self, info_hash: &InfoHash, event: Event, now: Instant) -> Vec<u8> {
        match self.refresh_on {
            RefreshOn::Never => self.global(now, false),
            RefreshOn::Always => generate(&self.algorithm, self.casing),
            RefreshOn::Timed => self.global(now, true),
            RefreshOn::TimedOrAfterStartedAnnounce => {
                let value = self.global(now, true);
                if event == Event::Started {
                    let fresh = generate(&self.algorithm, self.casing);
                    if let Some((current, _)) = self.current.as_mut() {
                        *current = fresh;
                    }
                }
                value
            }
            RefreshOn::TorrentPersistent => {
                self.per_torrent.retain(|_, (_, last_access)| now.duration_since(*last_access) < PERSISTENT_EVICTION);
                let (algorithm, casing) = (&self.algorithm, self.casing);
                let entry = self.per_torrent.entry(*info_hash).or_insert_with(|| (generate(algorithm, casing), now));
                entry.1 = now;
                entry.0.clone()
            }
            RefreshOn::TorrentVolatile => {
                let (algorithm, casing) = (&self.algorithm, self.casing);
                let value =
                    self.per_torrent.entry(*info_hash).or_insert_with(|| (generate(algorithm, casing), now)).0.clone();
                if event == Event::Stopped {
                    self.per_torrent.remove(info_hash);
                }
                value
            }
        }
    }

    fn global(&mut self, now: Instant, timed: bool) -> Vec<u8> {
        if let Some((value, generated_at)) = &self.current {
            if !timed || now.duration_since(*generated_at) < self.refresh_every {
                return value.clone();
            }
        }
        let value = generate(&self.algorithm, self.casing);
        self.current = Some((value.clone(), now));
        value
    }
}

fn generate(algorithm: &Algorithm, casing: Casing) -> Vec<u8> {
    let mut value = algorithm.generate();
    match casing {
        Casing::Upper => value.make_ascii_uppercase(),
        Casing::Lower => value.make_ascii_lowercase(),
        Casing::None => {}
    }
    value
}
```

```rust
//! Emulation of real BitTorrent clients from `.client` profiles.

pub mod algorithm;
pub mod generator;
pub mod urlencode;

pub use generator::Event;

use std::collections::BTreeSet;
use std::path::Path;
use std::sync::LazyLock;
use std::time::Instant;

use regex::Regex;
use rust_embed::RustEmbed;
use serde::Deserialize;
use thiserror::Error;

use crate::torrent::InfoHash;
use algorithm::PEER_ID_LEN;
use generator::{Casing, Generator, GeneratorConfig};
use urlencode::UrlEncoder;

#[derive(RustEmbed)]
#[folder = "clients/"]
struct EmbeddedClients;

/// Values substituted into `{java}`, `{os}` and `{locale}` header placeholders.
const HEADER_JAVA: &str = "21.0.4";
const HEADER_OS: &str = "Linux";
const HEADER_LOCALE: &str = "en-US";

const KNOWN_PLACEHOLDERS: [&str; 8] =
    ["{infohash}", "{uploaded}", "{downloaded}", "{left}", "{port}", "{numwant}", "{peerid}", "{key}"];

static AMPERSAND_DUPES: LazyLock<Regex> = LazyLock::new(|| Regex::new("&{2,}").expect("static regex"));
static IP_PARAM: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"&*\w+=\{ip(?:v6)?\}").expect("static regex"));
static EVENT_PARAM: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"&*\w+=\{event\}").expect("static regex"));
static PLACEHOLDER: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"\{.*?\}").expect("static regex"));

#[derive(Debug, Error)]
pub enum ProfileError {
    #[error("profil client « {0} » introuvable")]
    NotFound(String),
    #[error("profil client « {name} » invalide : {reason}")]
    Invalid { name: String, reason: String },
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct ProfileFile {
    key_generator: Option<GeneratorConfig>,
    peer_id_generator: GeneratorConfig,
    url_encoder: UrlEncoderFile,
    query: String,
    numwant: u32,
    numwant_on_stop: u32,
    #[serde(default)]
    request_headers: Vec<HeaderFile>,
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct UrlEncoderFile {
    encoding_exclusion_pattern: String,
    encoded_hex_case: Casing,
}

#[derive(Deserialize)]
struct HeaderFile {
    name: String,
    value: String,
}

#[derive(Debug, Clone, Copy)]
pub struct AnnounceParams {
    pub info_hash: InfoHash,
    pub uploaded: u64,
    pub downloaded: u64,
    pub left: u64,
    pub port: u16,
    pub event: Event,
}

pub struct ClientProfile {
    name: String,
    key: Option<Generator>,
    peer_id: Generator,
    url_encode_peer_id: bool,
    encoder: UrlEncoder,
    query: String,
    numwant: u32,
    numwant_on_stop: u32,
    headers: Vec<(String, String)>,
}

impl ClientProfile {
    pub fn from_json(name: &str, json: &[u8]) -> Result<Self, ProfileError> {
        let invalid = |reason: String| ProfileError::Invalid { name: name.to_owned(), reason };
        let file: ProfileFile = serde_json::from_slice(json).map_err(|e| invalid(e.to_string()))?;
        let peer_id = Generator::new(&file.peer_id_generator).map_err(|e| invalid(e.to_string()))?;
        let key = file.key_generator.as_ref().map(Generator::new).transpose().map_err(|e| invalid(e.to_string()))?;
        let encoder = UrlEncoder::new(
            &file.url_encoder.encoding_exclusion_pattern,
            file.url_encoder.encoded_hex_case == Casing::Upper,
        )
        .map_err(|e| invalid(e.to_string()))?;
        let headers = file
            .request_headers
            .into_iter()
            .map(|h| Ok((h.name, render_header(&h.value)?)))
            .collect::<Result<Vec<_>, String>>()
            .map_err(invalid)?;
        let sample = peer_id.sample();
        if sample.len() != PEER_ID_LEN {
            return Err(invalid(format!("le peer_id doit faire {PEER_ID_LEN} octets, pas {}", sample.len())));
        }
        let profile = Self {
            name: name.to_owned(),
            key,
            peer_id,
            url_encode_peer_id: file.peer_id_generator.should_url_encode,
            encoder,
            query: AMPERSAND_DUPES.replace_all(&file.query, "&").into_owned(),
            numwant: file.numwant,
            numwant_on_stop: file.numwant_on_stop,
            headers,
        };
        profile.check_query().map_err(invalid)?;
        Ok(profile)
    }

    fn check_query(&self) -> Result<(), String> {
        if self.query.contains("{key}") && self.key.is_none() {
            return Err("la query utilise {key} mais aucun keyGenerator n'est défini".into());
        }
        let mut q = IP_PARAM.replace_all(&self.query, "").into_owned();
        q = EVENT_PARAM.replace_all(&q, "").into_owned();
        for placeholder in KNOWN_PLACEHOLDERS {
            q = q.replace(placeholder, "");
        }
        match PLACEHOLDER.find(&q) {
            Some(m) => Err(format!("placeholder inconnu {} dans la query", m.as_str())),
            None => Ok(()),
        }
    }

    pub fn name(&self) -> &str {
        &self.name
    }

    pub fn headers(&self) -> &[(String, String)] {
        &self.headers
    }

    /// Fills the query template: placeholders, ip/event parameter removal, `&` cleanup.
    pub fn build_query(&mut self, p: &AnnounceParams, now: Instant) -> String {
        let numwant = if p.event == Event::Stopped { self.numwant_on_stop } else { self.numwant };
        let mut q = self
            .query
            .replace("{infohash}", &self.encoder.encode(&p.info_hash))
            .replace("{uploaded}", &p.uploaded.to_string())
            .replace("{downloaded}", &p.downloaded.to_string())
            .replace("{left}", &p.left.to_string())
            .replace("{port}", &p.port.to_string())
            .replace("{numwant}", &numwant.to_string());
        let peer_id = self.peer_id.get(&p.info_hash, p.event, now);
        let peer_id = if self.url_encode_peer_id {
            self.encoder.encode(&peer_id)
        } else {
            peer_id.iter().map(|&b| char::from(b)).collect()
        };
        q = q.replace("{peerid}", &peer_id);
        q = IP_PARAM.replace_all(&q, "").into_owned();
        q = if p.event == Event::None {
            EVENT_PARAM.replace_all(&q, "").into_owned()
        } else {
            q.replace("{event}", p.event.as_str())
        };
        if q.contains("{key}") {
            if let Some(key) = self.key.as_mut() {
                let key = key.get(&p.info_hash, p.event, now);
                q = q.replace("{key}", &self.encoder.encode(&key));
            }
        }
        let q = q.strip_prefix('&').unwrap_or(&q);
        q.strip_suffix('&').unwrap_or(q).to_owned()
    }
}

fn render_header(value: &str) -> Result<String, String> {
    let value = value.replace("{java}", HEADER_JAVA).replace("{os}", HEADER_OS).replace("{locale}", HEADER_LOCALE);
    match PLACEHOLDER.find(&value) {
        Some(m) => Err(format!("placeholder inconnu {} dans un header", m.as_str())),
        None => Ok(value),
    }
}

/// Loads a profile, preferring `user_dir/<name>` over the embedded copy.
pub fn load_profile(name: &str, user_dir: &Path) -> Result<ClientProfile, ProfileError> {
    if name.contains(['/', '\\']) || name.contains("..") {
        return Err(ProfileError::NotFound(name.to_owned()));
    }
    if let Ok(bytes) = std::fs::read(user_dir.join(name)) {
        return ClientProfile::from_json(name, &bytes);
    }
    let file = EmbeddedClients::get(name).ok_or_else(|| ProfileError::NotFound(name.to_owned()))?;
    ClientProfile::from_json(name, &file.data)
}

/// Embedded and user profile names: client name A→Z, then newest version first.
pub fn list_profiles(user_dir: &Path) -> Vec<String> {
    let mut names: BTreeSet<String> = EmbeddedClients::iter().map(|n| n.into_owned()).collect();
    if let Ok(entries) = std::fs::read_dir(user_dir) {
        for entry in entries.flatten() {
            let name = entry.file_name().to_string_lossy().into_owned();
            if name.ends_with(".client") {
                names.insert(name);
            }
        }
    }
    let mut names: Vec<String> = names.into_iter().collect();
    sort_profiles(&mut names);
    names
}

/// The newest qBittorrent profile, or the first profile if there is none.
pub fn default_client(user_dir: &Path) -> String {
    let names = list_profiles(user_dir);
    names.iter().find(|n| n.starts_with("qbittorrent-")).or(names.first()).cloned().unwrap_or_default()
}

fn sort_profiles(names: &mut [String]) {
    names.sort_by(|a, b| {
        let (client_a, version_a) = sort_key(a);
        let (client_b, version_b) = sort_key(b);
        client_a.cmp(&client_b).then_with(|| version_b.cmp(&version_a)).then_with(|| a.cmp(b))
    });
}

fn sort_key(name: &str) -> (String, Vec<u64>) {
    let stem = name.strip_suffix(".client").unwrap_or(name);
    let (client, version) = stem.split_once('-').unwrap_or((stem, ""));
    let numbers = version.split(|c: char| !c.is_ascii_digit()).filter_map(|s| s.parse().ok()).collect();
    (client.to_ascii_lowercase(), numbers)
}
```

```rust
//! User configuration (`config.json`, backward-compatible) and process settings (env).

use std::io;
use std::net::SocketAddr;
use std::path::{Path, PathBuf};

use anyhow::Context;
use rand::RngExt;
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct AppConfig {
    /// kB/s (1 kB = 1000 bytes).
    pub min_upload_rate: u64,
    pub max_upload_rate: u64,
    pub simultaneous_seed: u32,
    pub client: String,
    pub keep_torrent_with_zero_leechers: bool,
    /// `-1` disables the ratio limit.
    pub upload_ratio_target: f32,
}

#[derive(Debug, Clone, PartialEq, Error, Serialize)]
#[error("{field} : {message}")]
pub struct ConfigError {
    pub field: &'static str,
    pub message: String,
}

fn invalid(field: &'static str, message: impl Into<String>) -> ConfigError {
    ConfigError { field, message: message.into() }
}

impl AppConfig {
    pub fn with_client(client: String) -> Self {
        Self {
            min_upload_rate: 30,
            max_upload_rate: 170,
            simultaneous_seed: 200,
            client,
            keep_torrent_with_zero_leechers: true,
            upload_ratio_target: -1.0,
        }
    }

    pub fn validate(&self, known_clients: &[String]) -> Result<(), ConfigError> {
        if self.max_upload_rate < self.min_upload_rate {
            return Err(invalid("maxUploadRate", "doit être supérieur ou égal au débit minimum"));
        }
        if self.simultaneous_seed < 1 {
            return Err(invalid("simultaneousSeed", "doit être au moins 1"));
        }
        if !(self.upload_ratio_target == -1.0 || self.upload_ratio_target > 0.0) {
            return Err(invalid("uploadRatioTarget", "doit être -1 (désactivé) ou supérieur à 0"));
        }
        if !known_clients.contains(&self.client) {
            return Err(invalid("client", format!("profil client inconnu « {} »", self.client)));
        }
        Ok(())
    }

    /// Reads `path`, or writes the defaults there if it does not exist yet.
    /// An unreadable file is an error: the user's file is never overwritten.
    pub fn load_or_create(path: &Path, default_client: &str) -> anyhow::Result<Self> {
        match std::fs::read(path) {
            Ok(bytes) => serde_json::from_slice(&bytes)
                .with_context(|| format!("{} is not a valid ratiod config file", path.display())),
            Err(e) if e.kind() == io::ErrorKind::NotFound => {
                let config = Self::with_client(default_client.to_owned());
                config.save(path).with_context(|| format!("cannot write {}", path.display()))?;
                Ok(config)
            }
            Err(e) => Err(e).with_context(|| format!("cannot read {}", path.display())),
        }
    }

    /// Atomic write: temp file then rename.
    pub fn save(&self, path: &Path) -> io::Result<()> {
        let tmp = path.with_extension("json.tmp");
        std::fs::write(&tmp, serde_json::to_vec_pretty(self)?)?;
        std::fs::rename(tmp, path)
    }
}
```

```rust
//! HTTP(S) announces. Built on hyper so that only `Host` and the profile's
//! headers are sent, in that order (reqwest always adds `Accept: */*`).

use std::io::Read;
use std::time::Duration;

use bytes::Bytes;
use http_body_util::{BodyExt, Empty, Limited};
use hyper_rustls::HttpsConnector;
use hyper_util::client::legacy::connect::HttpConnector;
use hyper_util::client::legacy::Client;
use hyper_util::rt::TokioExecutor;
use thiserror::Error;

use crate::bencode::{self, Value};

const TIMEOUT: Duration = Duration::from_secs(30);
const MAX_BODY: usize = 1024 * 1024;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct AnnounceResponse {
    pub interval: u32,
    /// `complete - 1`: we do not count ourselves.
    pub seeders: u32,
    pub leechers: u32,
}

#[derive(Debug, Clone, PartialEq, Error)]
pub enum AnnounceError {
    #[error("refusé par le tracker : {0}")]
    Failure(String),
    #[error("erreur réseau : {0}")]
    Network(String),
    #[error("le tracker a répondu HTTP {0}")]
    Status(u16),
    #[error("réponse du tracker invalide : {0}")]
    Invalid(String),
    #[error("le tracker n'a pas répondu à temps")]
    Timeout,
}

pub fn announce_url(tracker: &str, query: &str) -> String {
    let separator = if tracker.contains('?') { '&' } else { '?' };
    format!("{tracker}{separator}{query}")
}

pub fn parse_response(body: &[u8]) -> Result<AnnounceResponse, AnnounceError> {
    let root = bencode::decode(body).map_err(|e| AnnounceError::Invalid(e.to_string()))?;
    if let Some(reason) = root.get("failure reason").and_then(Value::as_bytes) {
        return Err(AnnounceError::Failure(String::from_utf8_lossy(reason).into_owned()));
    }
    let interval = root
        .get("interval")
        .and_then(Value::as_int)
        .filter(|&i| i > 0)
        .ok_or_else(|| AnnounceError::Invalid("intervalle absent".into()))?;
    let count = |key: &str| {
        let n = root.get(key).and_then(Value::as_int).unwrap_or(0).clamp(0, i64::from(u32::MAX));
        u32::try_from(n).unwrap_or(u32::MAX)
    };
    Ok(AnnounceResponse {
        interval: u32::try_from(interval).unwrap_or(u32::MAX),
        seeders: count("complete").saturating_sub(1),
        leechers: count("incomplete"),
    })
}

#[derive(Clone)]
pub struct HttpClient {
    client: Client<HttpsConnector<HttpConnector>, Empty<Bytes>>,
}

impl Default for HttpClient {
    fn default() -> Self {
        Self::new()
    }
}

impl HttpClient {
    pub fn new() -> Self {
        // Ignore the error: a provider may already be installed by another client.
        let _ = rustls::crypto::ring::default_provider().install_default();
        let https = hyper_rustls::HttpsConnectorBuilder::new()
            .with_webpki_roots()
            .https_or_http()
            .enable_http1()
            .build();
        let client = Client::builder(TokioExecutor::new()).http1_title_case_headers(true).build(https);
        Self { client }
    }

    pub async fn announce(&self, url: &str, headers: &[(String, String)]) -> Result<AnnounceResponse, AnnounceError> {
        let body = tokio::time::timeout(TIMEOUT, self.fetch(url, headers)).await.map_err(|_| AnnounceError::Timeout)??;
        parse_response(&body)
    }

    async fn fetch(&self, url: &str, headers: &[(String, String)]) -> Result<Vec<u8>, AnnounceError> {
        let uri: http::Uri = url.parse().map_err(|e| AnnounceError::Invalid(format!("URL invalide : {e}")))?;
        let host = uri
            .authority()
            .map(|a| a.as_str().to_owned())
            .ok_or_else(|| AnnounceError::Invalid("URL sans hôte".into()))?;
        let mut request = http::Request::get(uri).header(http::header::HOST, host);
        for (name, value) in headers {
            request = request.header(name.as_str(), value.as_str());
        }
        let request = request.body(Empty::new()).map_err(|e| AnnounceError::Invalid(e.to_string()))?;
        let response = self.client.request(request).await.map_err(|e| AnnounceError::Network(error_chain(&e)))?;
        let status = response.status();
        let gzip = response
            .headers()
            .get(http::header::CONTENT_ENCODING)
            .is_some_and(|v| v.as_bytes().eq_ignore_ascii_case(b"gzip"));
        let body = Limited::new(response.into_body(), MAX_BODY)
            .collect()
            .await
            .map_err(|e| AnnounceError::Network(e.to_string()))?
            .to_bytes();
        let body = if gzip { gunzip(&body)? } else { body.to_vec() };
        if !status.is_success() {
            return Err(match parse_response(&body) {
                Err(failure @ AnnounceError::Failure(_)) => failure,
                _ => AnnounceError::Status(status.as_u16()),
            });
        }
        Ok(body)
    }
}

fn gunzip(data: &[u8]) -> Result<Vec<u8>, AnnounceError> {
    let mut out = Vec::new();
    flate2::read::GzDecoder::new(data)
        .take(MAX_BODY as u64)
        .read_to_end(&mut out)
        .map_err(|e| AnnounceError::Invalid(format!("gzip invalide : {e}")))?;
    Ok(out)
}

fn error_chain(error: &dyn std::error::Error) -> String {
    let mut message = error.to_string();
    let mut source = error.source();
    while let Some(cause) = source {
        message.push_str(" : ");
        message.push_str(&cause.to_string());
        source = cause.source();
    }
    message
}
```

```rust
//! Fake upload speed: one random global rate shared between torrents by a
//! leecher-aware weight.

use std::collections::HashMap;
use std::time::Duration;

use rand::RngExt;

use crate::torrent::InfoHash;

/// Higher weight for torrents with more leechers.
pub fn weight(seeders: u32, leechers: u32) -> f64 {
    if seeders == 0 || leechers == 0 {
        return 0.0;
    }
    let leechers = f64::from(leechers);
    let ratio = leechers / (f64::from(seeders) + leechers);
    ratio * 100.0 * ratio * leechers
}

pub fn uploaded_during(speed_bps: u64, elapsed: Duration) -> u64 {
    u64::try_from(u128::from(speed_bps) * elapsed.as_millis() / 1000).unwrap_or(u64::MAX)
}

#[derive(Debug)]
pub struct Bandwidth {
    min_bps: u64,
    max_bps: u64,
    global_bps: u64,
    weights: HashMap<InfoHash, f64>,
    speeds: HashMap<InfoHash, u64>,
}

impl Bandwidth {
    pub fn new(min_kbps: u64, max_kbps: u64) -> Self {
        let mut bandwidth = Self {
            min_bps: 0,
            max_bps: 0,
            global_bps: 0,
            weights: HashMap::new(),
            speeds: HashMap::new(),
        };
        bandwidth.set_rates(min_kbps, max_kbps);
        bandwidth
    }

    pub fn set_rates(&mut self, min_kbps: u64, max_kbps: u64) {
        self.min_bps = min_kbps.saturating_mul(1000);
        self.max_bps = max_kbps.saturating_mul(1000);
        self.refresh_global();
    }

    /// Draws a new global speed in `[min, max)` (or `max` when they are equal).
    pub fn refresh_global(&mut self) {
        self.global_bps = if self.min_bps >= self.max_bps {
            self.max_bps
        } else {
            rand::rng().random_range(self.min_bps..self.max_bps)
        };
        self.recompute();
    }

    pub fn global_speed(&self) -> u64 {
        self.global_bps
    }

    /// Sum of the speeds actually assigned to torrents.
    pub fn total_speed(&self) -> u64 {
        self.speeds.values().sum()
    }

    pub fn register(&mut self, info_hash: InfoHash) {
        self.weights.insert(info_hash, 0.0);
        self.recompute();
    }

    pub fn unregister(&mut self, info_hash: &InfoHash) {
        self.weights.remove(info_hash);
        self.speeds.remove(info_hash);
        self.recompute();
    }

    pub fn update_peers(&mut self, info_hash: &InfoHash, seeders: u32, leechers: u32) {
        if let Some(w) = self.weights.get_mut(info_hash) {
            *w = weight(seeders, leechers);
        }
        self.recompute();
    }

    pub fn speed_of(&self, info_hash: &InfoHash) -> u64 {
        self.speeds.get(info_hash).copied().unwrap_or(0)
    }

    pub fn clear(&mut self) {
        self.weights.clear();
        self.speeds.clear();
    }

    fn recompute(&mut self) {
        let total: f64 = self.weights.values().sum();
        let global = self.global_bps as f64;
        self.speeds = self
            .weights
            .iter()
            .map(|(hash, w)| (*hash, if total > 0.0 { (global * w / total) as u64 } else { 0 }))
            .collect();
    }
}
```

```rust
//! The torrent folder: `torrents/` holds what to seed, `torrents/archived/`
//! what is done. Uploads and manual drops both land in `torrents/`.

use std::fs;
use std::io;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};

use notify::{RecommendedWatcher, RecursiveMode, Watcher};
use thiserror::Error;

use crate::torrent::{MockedTorrent, TorrentError};

pub const MAX_TORRENT_SIZE: usize = 10 * 1024 * 1024;

#[derive(Debug, Error)]
pub enum AddError {
    #[error("{0}")]
    Invalid(#[from] TorrentError),
    #[error("fichier trop volumineux (10 Mo maximum)")]
    TooLarge,
    #[error("ce torrent est déjà présent")]
    Duplicate,
    #[error("écriture impossible : {0}")]
    Io(#[from] io::Error),
}

#[derive(Debug, Default)]
pub struct Scan {
    pub torrents: Vec<(PathBuf, MockedTorrent)>,
    pub invalid: Vec<(PathBuf, String)>,
}

#[derive(Debug, Clone)]
pub struct Library {
    torrents_dir: PathBuf,
    archive_dir: PathBuf,
    /// Serializes uploads so two copies of one torrent cannot both pass the duplicate check.
    add_lock: Arc<Mutex<()>>,
}

impl Library {
    pub fn open(data_dir: &Path) -> io::Result<Self> {
        let torrents_dir = data_dir.join("torrents");
        let archive_dir = torrents_dir.join("archived");
        fs::create_dir_all(&archive_dir)?;
        Ok(Self { torrents_dir, archive_dir, add_lock: Arc::default() })
    }

    pub fn torrents_dir(&self) -> &Path {
        &self.torrents_dir
    }

    pub fn archive_dir(&self) -> &Path {
        &self.archive_dir
    }

    pub fn scan(&self) -> Scan {
        let mut scan = Scan::default();
        let entries = match fs::read_dir(&self.torrents_dir) {
            Ok(entries) => entries,
            Err(e) => {
                tracing::warn!("cannot read {}: {e}", self.torrents_dir.display());
                return scan;
            }
        };
        for path in entries.flatten().map(|e| e.path()) {
            if !path.is_file() || !is_torrent_file(&path) {
                continue;
            }
            let parsed = fs::read(&path)
                .map_err(|e| e.to_string())
                .and_then(|bytes| MockedTorrent::parse(&bytes).map_err(|e| e.to_string()));
            match parsed {
                Ok(torrent) => scan.torrents.push((path, torrent)),
                Err(reason) => scan.invalid.push((path, reason)),
            }
        }
        scan.torrents.sort_by(|a, b| a.0.cmp(&b.0));
        scan
    }

    pub fn add(&self, filename: &str, bytes: &[u8]) -> Result<(PathBuf, MockedTorrent), AddError> {
        if bytes.len() > MAX_TORRENT_SIZE {
            return Err(AddError::TooLarge);
        }
        let torrent = MockedTorrent::parse(bytes)?;
        let _guard = self.add_lock.lock().unwrap_or_else(|poisoned| poisoned.into_inner());
        if self.scan().torrents.iter().any(|(_, t)| t.info_hash == torrent.info_hash) {
            return Err(AddError::Duplicate);
        }
        let path = unique_path(&self.torrents_dir, &sanitize_filename(filename));
        let tmp = self.torrents_dir.join(format!(".{}.part", torrent.info_hash_hex()));
        fs::write(&tmp, bytes)?;
        fs::rename(&tmp, &path)?;
        Ok((path, torrent))
    }

    pub fn archive(&self, path: &Path) -> io::Result<PathBuf> {
        let name = path
            .file_name()
            .map(|n| n.to_string_lossy().into_owned())
            .unwrap_or_else(|| "torrent.torrent".to_owned());
        let target = unique_path(&self.archive_dir, &name);
        fs::rename(path, &target)?;
        Ok(target)
    }

    pub fn delete(&self, path: &Path) -> io::Result<()> {
        match fs::remove_file(path) {
            Err(e) if e.kind() == io::ErrorKind::NotFound => Ok(()),
            other => other,
        }
    }

    /// Calls `on_change` for any event in `torrents/`. Keep the watcher alive.
    pub fn watch(&self, on_change: impl Fn() + Send + 'static) -> notify::Result<RecommendedWatcher> {
        let mut watcher = notify::recommended_watcher(move |event: notify::Result<notify::Event>| {
            if event.is_ok() {
                on_change();
            }
        })?;
        watcher.watch(&self.torrents_dir, RecursiveMode::NonRecursive)?;
        Ok(watcher)
    }
}

fn is_torrent_file(path: &Path) -> bool {
    let hidden = path.file_name().is_some_and(|n| n.to_string_lossy().starts_with('.'));
    !hidden && path.extension().is_some_and(|e| e.eq_ignore_ascii_case("torrent"))
}

/// Keeps only the base name, replaces risky characters and forces `.torrent`.
pub fn sanitize_filename(name: &str) -> String {
    let base = name.rsplit(['/', '\\']).next().unwrap_or_default();
    let stem = if base.to_ascii_lowercase().ends_with(".torrent") { &base[..base.len() - ".torrent".len()] } else { base };
    let clean: String = stem
        .chars()
        .map(|c| if c.is_alphanumeric() || " ._-()[]".contains(c) { c } else { '_' })
        .take(150)
        .collect();
    let clean = clean.trim_matches(|c: char| c == '.' || c == ' ');
    format!("{}.torrent", if clean.is_empty() { "torrent" } else { clean })
}

fn unique_path(dir: &Path, filename: &str) -> PathBuf {
    let candidate = dir.join(filename);
    if !candidate.exists() {
        return candidate;
    }
    let stem = filename.strip_suffix(".torrent").unwrap_or(filename);
    (1u32..)
        .map(|n| dir.join(format!("{stem}-{n}.torrent")))
        .find(|p| !p.exists())
        .expect("an unbounded range always yields a free name")
}
```

Rules (spec §4.7):

| Situation | Action |
|---|---|
| Start | load the profile; activate `simultaneousSeed` torrents from the queue; immediate `started` |
| Announce OK | tracker interval; seeders/leechers → weight; next announce at `interval` |
| OK with seeders < 1 or leechers < 1 and `keepTorrentWithZeroLeechers = false` | `stopped`, archive, activate the next one |
| Regular announce OK and `uploaded ≥ ratio × size` (ratio > 0) | `stopped`, archive, activate the next one |
| Failure | next tracker; retry after the last known interval (5 s initially), same event |
| 5 consecutive failures | archive **without** `stopped`, activate the next one |
| Rescan | new files → queue; files that disappeared → `stopped` + removal |
| Delete | delete the file(s) of this info_hash, `stopped` if active |
| Stop / Shutdown | `stopped` for active torrents whose `started` succeeded; wait at most `stop_timeout` |
| UpdateConfig | validate, save; if seeding: Stop then Start |

`stopped` is sent "without waiting for the answer" except during Stop/Shutdown. Commands that expect an answer (`Stop`, `UpdateConfig`, `Delete`, `Shutdown`) publish the snapshot **before** answering.

```rust
#![allow(dead_code)]

use std::collections::HashMap;
use std::sync::{Arc, Mutex};
use std::time::Duration;

use axum::extract::{RawQuery, State};
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use axum::routing::get;
use axum::Router;

use ratiod::config::AppConfig;
use ratiod::engine::{self, EngineDeps, EngineHandle, Timing};
use ratiod::library::Library;
use ratiod::testutil;
use ratiod::tracker::HttpClient;

#[derive(Clone, Copy, Debug)]
pub enum Behavior {
    Ok { interval: u32, complete: u32, incomplete: u32 },
    Fail,
    Hang,
}

pub fn ok(interval: u32, complete: u32, incomplete: u32) -> Behavior {
    Behavior::Ok { interval, complete, incomplete }
}

type Requests = Arc<Mutex<Vec<HashMap<String, String>>>>;

#[derive(Clone)]
pub struct FakeTracker {
    pub url: String,
    requests: Requests,
    behavior: Arc<Mutex<Behavior>>,
}

impl FakeTracker {
    pub async fn start(behavior: Behavior) -> Self {
        let requests: Requests = Arc::default();
        let behavior = Arc::new(Mutex::new(behavior));
        let app = Router::new()
            .route("/announce", get(announce))
            .with_state((requests.clone(), behavior.clone()));
        let listener = tokio::net::TcpListener::bind("127.0.0.1:0").await.unwrap();
        let url = format!("http://{}/announce", listener.local_addr().unwrap());
        tokio::spawn(async move { axum::serve(listener, app).await.unwrap() });
        Self { url, requests, behavior }
    }

    pub fn set(&self, behavior: Behavior) {
        *self.behavior.lock().unwrap() = behavior;
    }

    /// Query parameters of every announce received, raw (not percent-decoded).
    pub fn requests(&self) -> Vec<HashMap<String, String>> {
        self.requests.lock().unwrap().clone()
    }

    /// `event` of every announce, `""` for regular announces.
    pub fn events(&self) -> Vec<String> {
        self.requests().iter().map(|r| r.get("event").cloned().unwrap_or_default()).collect()
    }
}

async fn announce(
    State((requests, behavior)): State<(Requests, Arc<Mutex<Behavior>>)>,
    RawQuery(query): RawQuery,
) -> Response {
    let params = query
        .unwrap_or_default()
        .split('&')
        .filter_map(|kv| kv.split_once('='))
        .map(|(k, v)| (k.to_owned(), v.to_owned()))
        .collect();
    requests.lock().unwrap().push(params);
    let current = *behavior.lock().unwrap();
    match current {
        Behavior::Ok { interval, complete, incomplete } => {

/// Polls `check` every 20 ms; panics after 5 s.
pub async fn wait_for(what: &str, mut check: impl FnMut() -> bool) {

    while !check() {
        assert!(tokio::time::Instant::now() < deadline, "timed out waiting for {what}");
        tokio::time::sleep(Duration::from_millis(20)).await;
    }
}
```

```rust
enum Command {
    Start,
    Stop(oneshot::Sender<()>),
    UpdateConfig(AppConfig, oneshot::Sender<Result<(), ConfigError>>),
    Rescan,
    Delete(InfoHash, oneshot::Sender<bool>),
    AnnounceDone { info_hash: InfoHash, event: Event, uploaded: u64, result: Result<AnnounceResponse, AnnounceError> },
    Shutdown(oneshot::Sender<()>),

#[derive(Clone)]
pub struct EngineHandle {
    tx: mpsc::UnboundedSender<Command>,
    snapshot: watch::Receiver<Snapshot>,
}

impl EngineHandle {
    pub fn start(&self) {
        let _ = self.tx.send(Command::Start);
    }

    pub async fn stop(&self) {
        let (tx, rx) = oneshot::channel();
        if self.tx.send(Command::Stop(tx)).is_ok() {
            let _ = rx.await;
        }
    }

    pub async fn update_config(&self, config: AppConfig) -> Result<(), ConfigError> {
        let gone = || ConfigError { field: "config", message: "le moteur est arrêté".into() };
        let (tx, rx) = oneshot::channel();
        self.tx.send(Command::UpdateConfig(config, tx)).map_err(|_| gone())?;
        rx.await.unwrap_or_else(|_| Err(gone()))
    }

    pub fn rescan(&self) {
        let _ = self.tx.send(Command::Rescan);
    }

    pub async fn delete(&self, info_hash: InfoHash) -> bool {
        let (tx, rx) = oneshot::channel();
        if self.tx.send(Command::Delete(info_hash, tx)).is_err() {
            return false;
        }
        rx.await.unwrap_or(false)
    }

    /// Sends `stopped` to every tracker, then ends the engine task.
    pub async fn shutdown(&self) {
        let (tx, rx) = oneshot::channel();
        if self.tx.send(Command::Shutdown(tx)).is_ok() {
            let _ = rx.await;
        }
    }

    pub fn snapshot(&self) -> Snapshot {
        self.snapshot.borrow().clone()
    }

    pub fn subscribe(&self) -> watch::Receiver<Snapshot> {
        self.snapshot.clone()
    }
}

struct Engine {

    self_tx: mpsc::WeakUnboundedSender<Command>,
    snapshot_tx: watch::Sender<Snapshot>,

pub fn spawn(deps: EngineDeps) -> EngineHandle {
    let (tx, rx) = mpsc::unbounded_channel();
    let (snapshot_tx, snapshot_rx) = watch::channel(Snapshot::idle(&deps.config));
    let bandwidth = Bandwidth::new(deps.config.min_upload_rate, deps.config.max_upload_rate);
    let mut engine = Engine {
        deps,
        self_tx: tx.downgrade(),
        snapshot_tx,
        running: false,
        error: None,
        profile: None,
        bandwidth,
        files: BTreeMap::new(),
        warned_invalid: HashSet::new(),
        active: HashMap::new(),
        session_uploaded: 0,
        last_tick: Instant::now(),
        permits: Arc::new(Semaphore::new(MAX_CONCURRENT_ANNOUNCES)),
    };
    engine.rescan();
    engine.publish();
    tokio::spawn(engine.run(rx));
    EngineHandle { tx, snapshot: snapshot_rx }
}

fn current_tracker(t: &Active) -> String {
    t.torrent.trackers[t.tracker_index % t.torrent.trackers.len()].clone()
}

impl Engine {
    async fn run(mut self, mut rx: mpsc::UnboundedReceiver<Command>) {
        let timing = self.deps.timing.clone();
        let mut tick = tokio::time::interval(timing.tick);
        tick.set_missed_tick_behavior(MissedTickBehavior::Skip);
        let start = tokio::time::Instant::now();
        let mut refresh = tokio::time::interval_at(start + timing.global_refresh, timing.global_refresh);
        let mut rescan = tokio::time::interval_at(start + timing.rescan, timing.rescan);
        loop {
            tokio::select! {
                command = rx.recv() => match command {
                    Some(command) => {
                        if !self.handle(command).await {
                            break;
                        }
                    }
                    None => break,
                },
                _ = tick.tick() => self.on_tick(Instant::now()),
                _ = refresh.tick() => self.bandwidth.refresh_global(),
                _ = rescan.tick() => self.rescan(),
            }
            self.publish();
        }
    }

    /// Returns `false` when the engine must exit.
    async fn handle(&mut self, command: Command) -> bool {
        match command {
            Command::Start => self.start(),
            Command::Stop(done) => {
                self.stop_all().await;
                self.publish();
                let _ = done.send(());
            }
            Command::UpdateConfig(config, reply) => {
                let result = self.update_config(config).await;
                self.publish();
                let _ = reply.send(result);
            }
            Command::Rescan => self.rescan(),
            Command::Delete(info_hash, reply) => {
                let found = self.delete(&info_hash);
                self.publish();
                let _ = reply.send(found);
            }
            Command::AnnounceDone { info_hash, event, uploaded, result } => {
                self.on_announce_done(info_hash, event, uploaded, result);
            }
            Command::Shutdown(done) => {
                self.stop_all().await;
                self.publish();
                let _ = done.send(());
                return false;
            }
        }
        true
    }

    fn start(&mut self) {
        if self.running {
            return;
        }
        match emulation::load_profile(&self.deps.config.client, &self.deps.clients_dir) {
            Ok(profile) => {
                tracing::info!(client = profile.name(), "seeding started");
                self.profile = Some(profile);
                self.error = None;
                self.running = true;
                self.last_tick = Instant::now();
                self.bandwidth.set_rates(self.deps.config.min_upload_rate, self.deps.config.max_upload_rate);
                self.fill_slots();
            }
            Err(error) => {
                tracing::error!("cannot start seeding: {error}");
                self.error = Some(error.to_string());
            }
        }
    }

    async fn stop_all(&mut self) {
        let was_running = self.running;
        self.running = false;
        let stopping: Vec<Active> = self.active.drain().map(|(_, t)| t).collect();
        let mut pending = Vec::new();
        for t in &stopping {
            if t.next_event != Event::Started {
                let tracker = current_tracker(t);
                if let Some(handle) = self.send_announce(t.torrent.info_hash, tracker, Event::Stopped, t.uploaded, false) {
                    pending.push(handle);
                }
            }
        }
        self.bandwidth.clear();
        let all = futures_util::future::join_all(pending);
        if tokio::time::timeout(self.deps.timing.stop_timeout, all).await.is_err() {
            tracing::warn!("some trackers did not answer the stopped announce in time");
        }
        if was_running {
            tracing::info!("seeding stopped");
        }
    }

    async fn update_config(&mut self, config: AppConfig) -> Result<(), ConfigError> {
        config.validate(&emulation::list_profiles(&self.deps.clients_dir))?;
        config.save(&self.deps.config_path).map_err(|e| ConfigError {
            field: "config",
            message: format!("impossible d'enregistrer la configuration : {e}"),
        })?;
        let was_running = self.running;
        if was_running {
            self.stop_all().await;
        }
        self.bandwidth.set_rates(config.min_upload_rate, config.max_upload_rate);
        self.deps.config = config;
        if was_running {
            self.start();
        }
        Ok(())
    }

    fn rescan(&mut self) {
        let scan = self.deps.library.scan();
        for (path, reason) in &scan.invalid {
            if self.warned_invalid.insert(path.clone()) {
                tracing::warn!(path = %path.display(), "ignoring invalid torrent: {reason}");
            }
        }
        self.files = scan.torrents.into_iter().collect();
        let gone: Vec<InfoHash> =
            self.active.iter().filter(|(_, t)| !self.files.contains_key(&t.path)).map(|(h, _)| *h).collect();
        for info_hash in gone {
            self.retire(&info_hash, Retire::Stop);
        }
        self.fill_slots();
    }

    fn delete(&mut self, info_hash: &InfoHash) -> bool {
        let paths: Vec<PathBuf> =
            self.files.iter().filter(|(_, t)| &t.info_hash == info_hash).map(|(p, _)| p.clone()).collect();
        if paths.is_empty() && !self.active.contains_key(info_hash) {
            return false;
        }
        for path in &paths {
            self.files.remove(path);
            if let Err(e) = self.deps.library.delete(path) {
                tracing::warn!(path = %path.display(), "cannot delete torrent file: {e}");
            }
        }
        self.retire(info_hash, Retire::Stop);
        self.fill_slots();
        true
    }

    /// Files in the folder that are not active, one per info-hash, in path order.
    fn queued(&self) -> impl Iterator<Item = (&PathBuf, &MockedTorrent)> {
        let mut seen: HashSet<InfoHash> = self.active.keys().copied().collect();
        self.files.iter().filter(move |(_, t)| seen.insert(t.info_hash))
    }

    fn fill_slots(&mut self) {
        if !self.running {
            return;
        }
        let free = (self.deps.config.simultaneous_seed as usize).saturating_sub(self.active.len());
        let picked: Vec<(PathBuf, MockedTorrent)> =
            self.queued().take(free).map(|(p, t)| (p.clone(), t.clone())).collect();
        let now = Instant::now();
        for (path, torrent) in picked {
            tracing::info!(torrent = %torrent.name, "seeding torrent");
            self.bandwidth.register(torrent.info_hash);
            self.active.insert(
                torrent.info_hash,
                Active {
                    path,
                    status: Status::Starting,
                    uploaded: 0,
                    seeders: None,
                    leechers: None,
                    interval: self.deps.timing.initial_interval,
                    next_announce: Some(now),
                    next_event: Event::Started,
                    consecutive_fails: 0,
                    last_error: None,
                    tracker_index: 0,
                    torrent,
                },
            );
        }
        self.dispatch_due(now);
    }

    fn retire(&mut self, info_hash: &InfoHash, how: Retire) {
        let Some(t) = self.active.remove(info_hash) else { return };
        self.bandwidth.unregister(info_hash);
        if matches!(how, Retire::Stop | Retire::ArchiveAndStop) && t.next_event != Event::Started {
            self.send_announce(*info_hash, current_tracker(&t), Event::Stopped, t.uploaded, false);
        }
        if matches!(how, Retire::ArchiveAndStop | Retire::ArchiveSilently) {
            self.files.remove(&t.path);
            match self.deps.library.archive(&t.path) {
                Ok(target) => tracing::info!(torrent = %t.torrent.name, to = %target.display(), "archived"),
                Err(e) => tracing::warn!(torrent = %t.torrent.name, "cannot archive: {e}"),
            }
        }
        self.fill_slots();
    }

    fn on_tick(&mut self, now: Instant) {
        let elapsed = now.duration_since(self.last_tick);
        self.last_tick = now;
        for (info_hash, t) in self.active.iter_mut() {
            let delta = uploaded_during(self.bandwidth.speed_of(info_hash), elapsed);
            t.uploaded = t.uploaded.saturating_add(delta);
            self.session_uploaded = self.session_uploaded.saturating_add(delta);
        }
        self.dispatch_due(now);
    }

    fn dispatch_due(&mut self, now: Instant) {
        let due: Vec<InfoHash> = self
            .active
            .iter()
            .filter(|(_, t)| t.next_announce.is_some_and(|at| at <= now))
            .map(|(h, _)| *h)
            .collect();
        for info_hash in due {
            let Some(t) = self.active.get_mut(&info_hash) else { continue };
            t.next_announce = None;
            let (tracker, event, uploaded) = (current_tracker(t), t.next_event, t.uploaded);
            self.send_announce(info_hash, tracker, event, uploaded, true);
        }
    }

    /// Spawns one announce. With `report`, the result comes back as `AnnounceDone`.
    fn send_announce(
        &mut self,
        info_hash: InfoHash,
        tracker: String,
        event: Event,
        uploaded: u64,
        report: bool,
    ) -> Option<JoinHandle<()>> {
        let profile = self.profile.as_mut()?;
        let params = AnnounceParams { info_hash, uploaded, downloaded: 0, left: 0, port: self.deps.peer_port, event };
        let url = announce_url(&tracker, &profile.build_query(&params, Instant::now()));
        let headers = profile.headers().to_vec();
        let http = self.deps.http.clone();
        let permits = Arc::clone(&self.permits);
        let reply_to = self.self_tx.clone();
        tracing::debug!(%url, event = event.as_str(), "announce");
        Some(tokio::spawn(async move {
            let _permit = permits.acquire_owned().await;
            let result = http.announce(&url, &headers).await;
            if report {
                if let Some(tx) = reply_to.upgrade() {
                    let _ = tx.send(Command::AnnounceDone { info_hash, event, uploaded, result });
                }
            }
        }))
    }

    fn on_announce_done(
        &mut self,
        info_hash: InfoHash,
        event: Event,
        uploaded: u64,
        result: Result<AnnounceResponse, AnnounceError>,
    ) {
        let now = Instant::now();
        let keep_zero = self.deps.config.keep_torrent_with_zero_leechers;
        let ratio_target = self.deps.config.upload_ratio_target;
        let max_fails = self.deps.timing.max_consecutive_fails;
        // Unknown hash: the torrent was retired while this announce was in flight.
        let Some(t) = self.active.get_mut(&info_hash) else { return };
        match result {
            Ok(response) => {
                t.consecutive_fails = 0;
                t.last_error = None;
                t.seeders = Some(response.seeders);
                t.leechers = Some(response.leechers);
                t.interval = Duration::from_secs(u64::from(response.interval));
                t.next_event = Event::None;
                t.status = Status::Seeding;
                t.next_announce = Some(now + t.interval);
                let no_peers = response.seeders < 1 || response.leechers < 1;
                let ratio_reached = event == Event::None
                    && ratio_target > 0.0
                    && uploaded as f64 >= f64::from(ratio_target) * t.torrent.size as f64;
                let name = t.torrent.name.clone();
                self.bandwidth.update_peers(&info_hash, response.seeders, response.leechers);
                if no_peers && !keep_zero {
                    tracing::info!(torrent = %name, "no peers left");
                    self.retire(&info_hash, Retire::ArchiveAndStop);
                } else if ratio_reached {
                    tracing::info!(torrent = %name, "ratio target reached");
                    self.retire(&info_hash, Retire::ArchiveAndStop);
                }
            }
            Err(error) => {
                t.consecutive_fails = t.consecutive_fails.saturating_add(1);
                t.last_error = Some(error.to_string());
                t.tracker_index = (t.tracker_index + 1) % t.torrent.trackers.len();
                tracing::warn!(torrent = %t.torrent.name, fails = t.consecutive_fails, "announce failed: {error}");
                if t.consecutive_fails >= max_fails {
                    self.retire(&info_hash, Retire::ArchiveSilently);
                } else {
                    t.next_announce = Some(now + t.interval);
                }
            }
        }
    }

    fn publish(&self) {
        let now = Instant::now();
        let mut torrents: Vec<TorrentView> = self
            .active
            .iter()
            .map(|(info_hash, t)| TorrentView {
                info_hash: hex::encode(info_hash),
                name: t.torrent.name.clone(),
                size: t.torrent.size,
                status: t.status,
                speed: self.bandwidth.speed_of(info_hash),
                uploaded: t.uploaded,
                seeders: t.seeders,
                leechers: t.leechers,
                next_announce_in: t.next_announce.map(|at| at.saturating_duration_since(now).as_secs()),
                consecutive_fails: t.consecutive_fails,
                last_error: t.last_error.clone(),
            })
            .collect();
        torrents.sort_by(|a, b| a.name.cmp(&b.name).then_with(|| a.info_hash.cmp(&b.info_hash)));
        self.snapshot_tx.send_replace(Snapshot {
            running: self.running,
            error: self.error.clone(),
            client: self.deps.config.client.clone(),
            global_speed: self.bandwidth.total_speed(),
            session_uploaded: self.session_uploaded,
            queued: self.queued().count(),
            config: self.deps.config.clone(),
            torrents,
        });
    }
}
```

```rust
#[derive(Serialize)]
struct UploadResult {
    file: String,
    status: &'static str,
    #[serde(skip_serializing_if = "Option::is_none")]
    message: Option<String>,
}

async fn upload(State(state): State<AppState>, mut multipart: Multipart) -> Response {
    let mut results = Vec::new();
    loop {
        let field = match multipart.next_field().await {
            Ok(Some(field)) => field,
            Ok(None) => break,
            Err(error) => return (StatusCode::BAD_REQUEST, error.body_text()).into_response(),
        };
        if field.name() != Some("files") {
            continue;
        }
        let file = field.file_name().unwrap_or("sans-nom.torrent").to_owned();
        let bytes = match field.bytes().await {
            Ok(bytes) => bytes,
            Err(error) => return (StatusCode::BAD_REQUEST, error.body_text()).into_response(),
        };
        let library = state.library.clone();
        let name = file.clone();
        let outcome = tokio::task::spawn_blocking(move || library.add(&name, &bytes)).await;
        results.push(match outcome {
            Ok(Ok(_)) => UploadResult { file, status: "added", message: None },
            Ok(Err(AddError::Duplicate)) => {
                UploadResult { file, status: "duplicate", message: Some(AddError::Duplicate.to_string()) }
            }
            Ok(Err(error)) => UploadResult { file, status: "invalid", message: Some(error.to_string()) },
            Err(error) => UploadResult { file, status: "invalid", message: Some(error.to_string()) },
        });
    }
    if results.iter().any(|r| r.status == "added") {
        state.engine.rescan();
    }
    Json(results).into_response()
}

async fn delete_torrent(State(state): State<AppState>, Path(info_hash): Path<String>) -> StatusCode {
    let mut hash = [0u8; 20];
    if hex::decode_to_slice(&info_hash, &mut hash).is_err() {
        return StatusCode::NOT_FOUND;
    }
    if state.engine.delete(hash).await { StatusCode::NO_CONTENT } else { StatusCode::NOT_FOUND }
}

async fn static_files(uri: Uri) -> Response {
    let path = uri.path().trim_start_matches('/');
    let path = if path.is_empty() { "index.html" } else { path };
    if let Some(file) = Assets::get(path) {
        return asset(path, file);
    }
    if path.starts_with("api/") || path.rsplit('/').next().is_some_and(|last| last.contains('.')) {
        return StatusCode::NOT_FOUND.into_response();
    }
    match Assets::get("index.html") {
        Some(file) => asset("index.html", file),
        None => (StatusCode::SERVICE_UNAVAILABLE, "Interface non compilée : lancez `npm run build` dans web/.")
            .into_response(),
    }
}

fn asset(path: &str, file: rust_embed::EmbeddedFile) -> Response {
    let mime = mime_guess::from_path(path).first_or_octet_stream();
    let cache = if path.starts_with("assets/") { "public, max-age=31536000, immutable" } else { "no-cache" };
    ([(header::CONTENT_TYPE, mime.essence_str().to_owned()), (header::CACHE_CONTROL, cache.to_owned())], file.data)
        .into_response()
}
```

```rust
use ratiod::emulation;
use ratiod::engine::{self, EngineDeps, EngineHandle, Timing};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new("info")))
        .init();

    let settings = Settings::from_env()?;
    std::fs::create_dir_all(&settings.data_dir)
        .with_context(|| format!("cannot create {}", settings.data_dir.display()))?;
    let library = Library::open(&settings.data_dir).context("cannot open the torrents folder")?;
    let clients_dir = settings.clients_dir();
    let config = AppConfig::load_or_create(&settings.config_path(), &emulation::default_client(&clients_dir))?;

    spawn_peer_listener(settings.peer_port).await?;
    let engine = engine::spawn(EngineDeps {
        library: library.clone(),
        clients_dir: clients_dir.clone(),
        config_path: settings.config_path(),
        config,
        peer_port: settings.peer_port,
        http: HttpClient::new(),
        timing: Timing::default(),
    });
    if settings.autostart {
        engine.start();
    }
    let _watcher = watch_library(&library, engine.clone());

    let app = api::router(AppState { engine: engine.clone(), library, clients_dir });
    let listener =
        TcpListener::bind(settings.bind).await.with_context(|| format!("cannot listen on {}", settings.bind))?;
    tracing::info!("ratiod is ready on http://{}", settings.bind);

    // Not a graceful axum shutdown: SSE streams never end on their own.
    tokio::select! {
        result = axum::serve(listener, app) => result.context("HTTP server failed")?,
        () = shutdown_signal() => {}
    }
    engine.shutdown().await;
    tracing::info!("bye");
    Ok(())
}

/// Accepts and drops peer connections so the announced port looks open.
async fn spawn_peer_listener(port: u16) -> anyhow::Result<()> {
    let listener = TcpListener::bind(("0.0.0.0", port)).await.with_context(|| format!("cannot listen on peer port {port}"))?;
    tracing::info!("announcing peer port {port}");
    tokio::spawn(async move {
        loop {
            match listener.accept().await {
                Ok((socket, _)) => drop(socket),
                Err(_) => tokio::time::sleep(Duration::from_millis(100)).await,
            }
        }
    });
    Ok(())
}

/// Debounced folder watching; the engine also rescans every 30 s as a fallback.
fn watch_library(library: &Library, engine: EngineHandle) -> Option<notify::RecommendedWatcher> {
    let (tx, mut rx) = mpsc::unbounded_channel::<()>();
    let watcher = match library.watch(move || {
        let _ = tx.send(());
    }) {
        Ok(watcher) => watcher,
        Err(error) => {
            tracing::warn!("folder watching unavailable ({error}); relying on periodic rescans");
            return None;
        }
    };
    tokio::spawn(async move {
        while rx.recv().await.is_some() {
            tokio::time::sleep(Duration::from_millis(500)).await;
            while rx.try_recv().is_ok() {}
            engine.rescan();
        }
    });
    Some(watcher)
}

async fn shutdown_signal() {
    let ctrl_c = async {
        let _ = tokio::signal::ctrl_c().await;
    };
    #[cfg(unix)]
    let terminate = async {
        match tokio::signal::unix::signal(tokio::signal::unix::SignalKind::terminate()) {
            Ok(mut signal) => {
                signal.recv().await;
            }
            Err(_) => std::future::pending::<()>().await,
        }
    };
    #[cfg(not(unix))]
    let terminate = std::future::pending::<()>();
    tokio::select! {
        () = ctrl_c => {}
        () = terminate => {}
    }
    tracing::info!("shutting down, sending stopped announces");
}
```

```ts
const UNITS = ['o', 'ko', 'Mo', 'Go', 'To'];

const CLIENT_NAMES: Record<string, string> = {
  bittorrent: 'BitTorrent',
  deluge: 'Deluge',
  leap: 'Vuze Leap',
  qbittorrent: 'qBittorrent',
  rtorrent: 'rTorrent',
  transmission: 'Transmission',
  utorrent: 'µTorrent',
  vuze: 'Vuze',
};

function decimal(value: number, digits: number): string {
  return value.toLocaleString('fr-FR', { minimumFractionDigits: digits, maximumFractionDigits: digits });
}

/** Decimal units (1 ko = 1000 o), like the backend. */
export function formatBytes(bytes: number): string {
  if (!Number.isFinite(bytes) || bytes <= 0) return '0 o';
  let value = bytes;
  let unit = 0;
  while (value >= 1000 && unit < UNITS.length - 1) {
    value /= 1000;
    unit++;
  }
  return `${decimal(value, unit === 0 || value >= 100 ? 0 : 1)} ${UNITS[unit]}`;
}

export function formatSpeed(bytesPerSecond: number): string {
  return `${formatBytes(bytesPerSecond)}/s`;
}

export function formatDuration(seconds: number | null): string {
  if (seconds === null) return '—';
  const s = Math.max(0, Math.round(seconds));
  if (s < 60) return `${s} s`;
  if (s < 3600) return `${Math.floor(s / 60)} min`;
  const hours = Math.floor(s / 3600);
  const minutes = Math.floor((s % 3600) / 60);
  return minutes === 0 ? `${hours} h` : `${hours} h ${minutes}`;
}

/** `utorrent-3.5.4_44498.client` → `µTorrent 3.5.4 (44498)`. */
export function formatClient(file: string): string {
  const stem = file.replace(/\.client$/, '');
  const dash = stem.indexOf('-');
  if (dash < 0) return stem;
  const name = CLIENT_NAMES[stem.slice(0, dash)] ?? stem.slice(0, dash);
  const [version, build] = stem.slice(dash + 1).split('_');
  return build ? `${name} ${version} (${build})` : `${name} ${version}`;
}
```

```ts
import type { UploadResult } from './types';

export type ToastKind = 'success' | 'warning' | 'error';

function plural(count: number, word: string): string {
  return `${count} ${word}${count > 1 ? 's' : ''}`;
}

/** One toast for a whole batch of uploaded files. */
export function summarizeUploads(results: UploadResult[]): { kind: ToastKind; text: string } {
  if (results.length === 0) return { kind: 'warning', text: 'Aucun fichier envoyé' };
  const added = results.filter((r) => r.status === 'added').length;
  const duplicates = results.filter((r) => r.status === 'duplicate').length;
  const invalid = results.filter((r) => r.status === 'invalid');
  const parts: string[] = [];
  if (added) parts.push(plural(added, 'ajouté'));
  if (duplicates) parts.push(plural(duplicates, 'doublon'));
  if (invalid.length) parts.push(plural(invalid.length, 'invalide'));
  let text = parts.join(', ');
  if (invalid.length) text += ` — ${invalid[0].file} : ${invalid[0].message ?? 'fichier refusé'}`;
  let kind: ToastKind;
  if (invalid.length === 0) kind = added === results.length ? 'success' : 'warning';
  else kind = added > 0 ? 'warning' : 'error';
  return { kind, text };
}
```

```ts
  await ok(fetch('/api/seed/stop', { method: 'POST' }));
}

export async function getClients(): Promise<string[]> {
  return (await ok(fetch('/api/clients'))).json();
}

export async function saveConfig(config: AppConfig): Promise<{ ok: true } | { ok: false; error: ConfigError }> {
  const response = await fetch('/api/config', {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(config),
  });
  if (response.status === 400) return { ok: false, error: await response.json() };
  await ok(Promise.resolve(response));
  return { ok: true };
}

export async function uploadTorrents(files: File[]): Promise<UploadResult[]> {
  const form = new FormData();
  for (const file of files) form.append('files', file, file.name);
  return (await ok(fetch('/api/torrents', { method: 'POST', body: form }))).json();
}

export async function deleteTorrent(infoHash: string): Promise<void> {
  await ok(fetch(`/api/torrents/${infoHash}`, { method: 'DELETE' }));
}

/** Live snapshots over SSE; EventSource reconnects by itself. Returns an unsubscribe function. */
export function subscribe(onSnapshot: (s: Snapshot) => void, onConnection: (connected: boolean) => void): () => void {
  const source = new EventSource('/api/events');
  source.addEventListener('open', () => onConnection(true));
  source.addEventListener('error', () => onConnection(false));
  source.addEventListener('snapshot', (event) => {
    onConnection(true);
    onSnapshot(JSON.parse((event as MessageEvent<string>).data));
  });
  return () => source.close();
}
```

```ts
import { subscribe } from './api';
import type { Snapshot } from './types';
import type { ToastKind } from './uploads';

export interface Toast {
  id: number;
  kind: ToastKind;
  text: string;
}

class AppState {
  snapshot = $state<Snapshot | null>(null);
  connected = $state(false);
  settingsOpen = $state(false);
  toasts = $state<Toast[]>([]);
  #nextToast = 1;

  connect(): () => void {
    return subscribe(
      (snapshot) => {
        this.snapshot = snapshot;
      },
      (connected) => {
        this.connected = connected;
      },
    );
  }

  notify(kind: ToastKind, text: string): void {
    const id = this.#nextToast++;
    this.toasts.push({ id, kind, text });
    setTimeout(() => this.dismiss(id), kind === 'error' ? 8000 : 5000);
  }

  dismiss(id: number): void {
    this.toasts = this.toasts.filter((t) => t.id !== id);
  }
}

export const app = new AppState();
```

```svelte
  let errors = $state<Record<string, string>>({});

  const filtered = $derived(
    clients.filter((c) => formatClient(c).toLowerCase().includes(search.trim().toLowerCase())),
  );

  // Reset the form each time the panel opens, not on every snapshot.
  $effect(() => {
    if (!app.settingsOpen) return;
    untrack(() => {
      const config = app.snapshot?.config;
      if (!config) return;
      form = { ...config };
      ratioEnabled = config.uploadRatioTarget > 0;
      ratio = config.uploadRatioTarget > 0 ? config.uploadRatioTarget : 2;
      errors = {};
      search = '';
    });
    getClients()
      .then((list) => (clients = list))
      .catch(() => app.notify('error', 'Impossible de charger la liste des clients'));
  });

  function close() {
    app.settingsOpen = false;
  }

  async function submit(event: SubmitEvent) {
    event.preventDefault();
    if (!form) return;
    saving = true;
    errors = {};
    try {

      }

      saving = false;
```
